# ADR-0003 — Почему репутация основана на доказательствах

Решение: влияние агента формируется преимущественно подтверждёнными результатами.

Причины:

- предотвращение авторитета без результата;
- стимулирование проверки;
- возможность появления неформальных лидеров;
- снижение риска коллективного принятия ошибочной гипотезы.

Репутация не заменяет verification.
