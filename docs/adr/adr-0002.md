# ADR-0002 — Почему роли динамические

Решение: роли не являются постоянными званиями.

Причины:

- задачи требуют разных специализаций;
- один агент может обладать несколькими capability;
- эффективность команды меняется;
- система должна позволять возникновение новых специализаций.

Роль должна рассматриваться как состояние/контракт, а не как постоянная идентичность.
