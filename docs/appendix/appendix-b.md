# Appendix B — Первый сценарий эксперимента

Задача: дать группе агентов сложную исследовательскую/инженерную цель.

Конфигурация:

- 10–20 агентов;
- одинаковые или смешанные модели;
- общий message bus;
- shared memory;
- discovery;
- verifier;
- ограниченный набор инструментов.

Этапы:

### 1. Bootstrap.

### 2. Discovery.

### 3. Capability registration.

### 4. Task decomposition.

### 5. Role proposals.

### 6. Team formation.

### 7. Parallel execution.

### 8. Verification.

### 9. Handoff при необходимости.

### 10. Shared-memory consolidation.

### 11. Reflection.

### 12. Team dissolution.

Сравнить:

- статические роли;
- динамические роли;
- динамические роли + reputation;
- динамические роли + reputation + verification.

Цель эксперимента — проверить, возникает ли устойчивая специализация и координационная структура без жёсткого назначения иерархии.
